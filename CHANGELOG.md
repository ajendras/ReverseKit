## [0.1.0] - 2026-11-14

### Added

- Universal Loader — Auto-detects and parses ELF, PE, Mach-O, DEX using LIEF with one command
- Capstone Disasm — Lightning-fast disassembly for x86, ARM, MIPS, RISC-V and WebAssembly
- CFG Builder — Generates control-flow graphs with NetworkX and exports to PNG, DOT or SVG
- Local AI Helper — Ollama integration renames functions, suggests variable names and adds comments
- Pattern Scanner — Detects common vulnerabilities, anti-debug tricks and library function signatures
- Rich Reports — Creates Markdown, JSON and interactive HTML reports with embedded visuals
- Python Library — Importable API for scripting custom analysis pipelines and automation
- String Explorer — Advanced string extraction, decoding and cross-reference mapping
- Symbol Recovery — Reconstructs stripped symbols and imports with FLIRT-style matching
